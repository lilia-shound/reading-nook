# 共读小屋 · 皮肤契约（写新皮肤必读）

> 每套皮肤一个独立文件，放在 `public/themes/<slug>.css`。
> 这样并行写不会互相踩，改一套也不用碰别的。

## 1. 你要交的文件

**只有一个**：`public/themes/<slug>.css`

**不要动**（这是别人的地盘，改了会冲突）：
- `public/app.js`
- `public/app.css`
- `public/index.html`
- `public/themes/` 下**别的**文件
- `CONTRACT.md`
- `test/` 下任何文件
- `data/` 下任何文件

## 2. CSS 变量契约（一个都不能少）

主题的所有视觉都由这组变量驱动，app.css 里所有组件都读它们。
**少一个变量，那一处就会掉回上一个主题的样子。**

```css
body[data-theme="<slug>"][data-mode="day"] {
  --bg:          /* 页面底色 */
  --bg-2:        /* 顶栏 / 工具栏 / 弹窗等"面" */
  --paper:       /* 正文纸面 */
  --ink:         /* 正文主色 */
  --ink-soft:    /* 次要文字 */
  --line:        /* 分隔线 / 描边 */
  --accent:      /* 强调色（按钮底、选中态） */
  --on-accent:   /* 强调色上的文字 */
  --hl-mine:     /* 我的划线色 */
  --hl-ai:       /* 他回完后的划线色 */
  --bub-mine:    /* 我的批注气泡底色 */
  --bub-ai:      /* 他的批注气泡底色 */
  --text-color:  /* 正文实际用色（--ink 的可覆盖版） */
  --radius:      /* 圆角（大） */
  --radius-sm:   /* 圆角（小） */
  --shadow:      /* 阴影（大） */
  --shadow-sm:   /* 阴影（小） */
  --font-serif:  /* 正文字体栈 */
  --font-sans:   /* 无衬线字体栈 */
  --danger:      /* 危险色（删按钮） */
  --deco:        /* 页面背景装饰（CSS 背景图，可多层） */
  --deco-size:   /* 装饰的尺寸（对应 --deco 的每一层） */
}
```

**`night` 档必须单独写一套**（`body[data-theme="<slug>"][data-mode="night"]`）。
昼夜两套的变量名完全一样，只是值不同。

## 3. 硬性要求

1. **零外部资源** —— 不许引 Google Fonts、不许引 CDN 图片。
   字体一律用系统字体栈，`--deco` 用 `data:image/svg+xml` 内联 SVG 或纯 CSS 渐变。
   （这套东西要能在没网的时候用）
2. **只在 `body[data-theme="<slug>"]` 作用域内生效**。
   任何一条规则都不能影响别的皮肤。
3. **夜间档必须真的能读** —— 深底 + 浅字，别把深色字配深色底。
4. **`--hl-mine` / `--hl-ai` 要是"划线"能看见的颜色。**
   浅色底配深色字（`--text-color` 要和它协调）。
5. **正文可读性优先** —— 这是一个读书的地方，正文行高和字号不能被风格牺牲。
6. 允许在 `body[data-theme="<slug>"]` 下给具体组件加风格化规则
   （`.btn` / `.book-card` / `.reader__content` / `.bubble` / `.sel-bar` / `.pill` 等），
   **但别动 app.css 里的通用规则**。

## 4. 头部注释

每个文件开头写清楚：这套风格叫什么、参考哪个 HTML、四条"铁律"是什么。
（现有三个主题都是这么写的，照着来）

```css
/**
 * 共读小屋 · 主题：<中文名> (<English>)
 *
 * 参考：_reference/ui/<参考文件>.html
 *
 * <这套风格的铁律，4 条左右>
 */
```

## 5. 自检

写完在项目根目录跑：

```bash
node test/check_css.js
```

这个测试会检查：类名齐不齐、主题块在不在、变量齐不齐、花括号平不平。
**你的主题名必须已经加进 `test/check_css.js` 的 THEMES 列表里**——
如果还没加，说明主流程还没挂上你，**先别管这个报错**，把文件写完交上来。

再自己确认一遍：

```bash
node -e "const c=require('fs').readFileSync('public/themes/<slug>.css','utf8');let d=0;for(const ch of c){if(ch==='{')d++;if(ch==='}')d--;}console.log('花括号平衡:',d===0?'OK':'不平衡 '+d)"
```

- 有没有用到 data-uri SVG（如果有，说一句画的是什么）
