# 剩下 4 套皮肤的参考要点（派活简报）

> 已派：material-design / neo-brutalism / acid-graphics / retrofuturism
> 待派：anti-design / brutalism / flat-design / minimalism

## Anti-Design（反设计）· slug: `anti-design`
参考：`_reference/ui/anti-design-components.html`（朋克版）+ `anti-design-components-lite.html`（温和版）

- 朋克版：底 `#2D2D2D`，等宽字体 `Space Mono`，大量 `transform: rotate`（×43）
- **双向偏移阴影**（签名）：
  - `12px 12px 0 #00FF00, -8px -8px 0 #0000FF`
  - `6px 6px 0 #FFFF00, -3px -3px 0 #FF00FF`
- 温和版：底 `#F8F5F0`，面板 `#FFFFFF`，强调 `#E8364E`，蓝 `#2D5BFF`、绿 `#22C55E`、黄 `#FACC15`
- 阴影：`6px 6px 0 var(--accent), -3px -3px 0 var(--blue)`
- **最容易翻车的一套** —— 铁律：歪斜只加在装饰元素（色卡/图标/封面/按钮），正文和卡片主体保持端正；正文区要留白

## Brutalism（粗野主义）· slug: `brutalism`
参考：`_reference/ui/brutalism-components.html`

- 底 `#2D2D2D`（深灰），正文 `#2D2D2D`
- 字体：`'Courier New', Courier, monospace`（全等宽！这是它的标志）
- 特征：`border-radius` 只出现 1 次（几乎零圆角）、`text-transform` ×3、`transform/rotate` ×2
- 字重 500
- 描述：「新粗野主义的前身，完全放弃装饰、结构外露，用纯粹功能性的元素直接呈现」
- **与 neo-brutalism 的区别**（要拉开距离）：
  - brutalism = 零装饰、零圆角、系统等宽、粗线条框、像终端/工程图纸
  - neo-brutalism = 粗黑边 + 偏移硬阴影 + 高饱和撞色 + 字重 900
- 铁律：零圆角 / 全等宽 / 边框粗而平 / 不加任何阴影和渐变

## Flat Design（扁平化）· slug: `flat-design`
参考：`_reference/ui/flat-design-components.html`

- 底 `#FFFFFF`，正文 `#2C3E50`，次要 `#95A5A6`，强调 `#3498DB`
- 边框 `#D5DCE6`
- 撞色：蓝 `#3498DB`、红 `#E74C3C`、绿 `#2ECC71`、橙 `#F39C12`、紫 `#9B59B6`
- 字体 `Inter`，字重 500/600/700/800
- 特征：`border-radius` ×16、**box-shadow 0 次**（扁平就是没阴影！）
- 描述：「作为对拟物化的"反叛"，其特点是简洁、二维、无阴影和纹理，强调内容本身」
- 铁律：**零阴影**（--shadow / --shadow-sm 给 `none` 或极淡）/ 纯色块 / 细边框 / 圆角适中

## Minimalism（极简）· slug: `minimalism`
参考：`_reference/ui/minimalism-components.html`

- 底 `#F7F7F7`，正文 `#1A1A1A`，次要 `#888888`
- 强调 `#1A1A1A`（就是黑！没有彩色强调色）
- 分隔线 `#E2E2E2`，输入框线 `#CCCCCC`
- 字体 `Inter`，字重 **300/400/500**（很轻！）
- 特征：`box-shadow` 只 1 次（`0 0 0 1px var(--divider) inset` —— 只有内描边）、`border-radius` ×7
- 描述：「"少即是多"。大量留白、无装饰的排版和有限的配色，只保留最核心的元素」
- 铁律：留白要舍得给 / 字重轻（300 为主）/ 只有黑白灰 / 唯一的强调色就是黑 / 阴影只留内描边
