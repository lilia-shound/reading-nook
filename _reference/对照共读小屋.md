# 对照：共读小屋现有主题 × 这 14 种经典风格

共读小屋现在有 8 套主题（每套 × 白天/夜间 = 16 套）。它们和这 14 种经典风格的关系：

| 共读小屋主题 | 对应的经典风格 | 关系 |
|---|---|---|
| 🐶 奶油小狗 | ≈ Minimalism / Flat Design | 同一个「少即是多」的底子，但配色更暖更甜，描边更软 |
| 🍵 抹茶老铺 | ≈ Material Design | 都强调清晰层级 + 好读性，抹茶的绿是 Material 3 那种沉稳主色 |
| 🌸 慕夏花神 | ≈ Acid Graphics（浅色版） | 都是高饱和粉紫撞色，只是慕夏花神更柔、没有酸性风的锐利直角 |
| 🎀 黑白甜 | ≈ Brutalism / Neo-Brutalism | 强对比、粗线条；这边是「甜版」暴力美学 |
| 💌 法式蓝笺 | ≈ Bauhaus | 几何构成 + 蓝色主调，都是「形式服务内容」 |
| 🧱 黏土 | = **Claymorphism** | 直接对应 |
| 🫧 新拟物 | = **Neumorphism** | 直接对应 |
| 🪟 拟态玻璃 | = **Glassmorphism** | 直接对应 |

## 参考里有、我们还没有的

| 风格 | 为什么值得加 | 适配共读小屋的哪个部分 |
|---|---|---|
| **Liquid Glass 液态玻璃** | 2024 起 Apple 带的下一代毛玻璃：模糊 + 折射 + 边缘高光 + 动态形变。共读小屋的「拟态玻璃」是上一代 | 整个外壳：顶栏、书架卡片、批注气泡都能吃到折射光 |
| **Skeuomorphism 拟物化** | 真·拟物（材质、纹理、真实投影），跟「黏土 / 新拟物」是完全不同的三兄弟 | 阅读器：纸张质感、翻页阴影、按钮的实体感 |
| **Material Design** | Google Material 3，层级阴影 + 动态主色 + 圆角系统 | 阅读器正文区最省眼睛，适合长时间读 |
| **Bauhaus 包豪斯** | 几何 + 红黄蓝三原色，克制而有识别度 | 书架、正文排版，装饰性背景 |
| **Acid Graphics 酸性图形** | 荧光撞色 + 网格 + 偏移硬阴影，迷幻但锐利 | 当彩蛋主题（夜间档很出彩） |
| **Retrofuturism 复古未来** | 70 年代太空手册 + 早期终端的印刷美学 | 夜间档彩蛋，等宽字体的实验感 |
| **Anti-Design 反设计** | 朋克、错位、故障、贴纸，故意不和谐 | 最适合当「吐槽彩蛋」主题 |
| **Minimalism / Flat Design** | 两个基础盘 | 长时间阅读的默认档 |

## 迁移成本（按现有代码估）

共读小屋 `public/app.css` 现在 63 KB / 8 套主题。参考里的示例是**组件展示页**（含播放器、标签页、调色板等我们没有的组件），所以不能整份搬。真要搬的是每套的**设计 token + 按钮 / 输入框 / 卡片样式**：

- 配色变量（`:root` 里的 `--xxx`）：直接照抄，已在 `UI风格参考.md` 里整理好
- 圆角 / 阴影 / 毛玻璃 / 渐变：抄
- 字体：参考用的是 Google Fonts（Inter / Orbitron / Share Tech Mono / Noto Sans SC），共读小屋现在是系统字体栈 —— 要换得考虑离线可用性

**每套新增主题约 6-10 KB CSS**。加 4 套 ≈ +30 KB，app.css 到 ~95 KB，完全可接受。
